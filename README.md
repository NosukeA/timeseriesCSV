# 時系列データアニメーター

CSVやExcel由来の時系列データから、プレゼン・SNS・説明資料に使える「伸びるグラフ動画」を作るローカルWebアプリです。

## 使い方

1. `index.html` をブラウザで開きます。開発時は `npm run dev` でも起動できます。
2. `CSVを読み込む`、または左側のサンプルCSVからデータを読み込みます。
3. `グラフ作成` で時系列列と複数の数値系列を選びます。
4. タイトル、サブタイトル、軸名、単位、注記、出典、色、テーマ、表示期間を調整します。
5. `アニメーション再生` で確認します。
6. `PNG保存` または `動画保存（WebM）` で書き出します。

## 主な機能

- 複数系列の同時表示
- 系列ごとの表示名、線色、点色の編集
- 凡例表示
- ホバー時の年・各系列値ツールチップ
- グラフタイトル、サブタイトル、軸名、単位、注記、出典の編集
- 1・2・5・10系の読みやすいY軸目盛り
- Y軸の0始まり/自動調整切り替え
- 対数スケール
- 表示期間指定
- 初年度=100の指数化
- 最終値ラベル
- 初年度比の倍率と年平均成長率
- テーマ、背景色、文字色、グリッド線色の変更
- PNG保存
- MediaRecorder APIによるWebM動画保存
- 動画時間、開始時停止、終了時停止の設定
- 複数サンプルCSV
- 世界銀行データを使ったサンプル（実質GDP、人口、1人あたりGDP、平均寿命、GDP成長率）
- データ診断
- 欠損値処理の選択
- データ確認タブでのCSV編集、検索、ソート、CSV保存

## デプロイ

Vercelでは `npm run build` を実行し、`dist/` を静的サイトとして配信します。
